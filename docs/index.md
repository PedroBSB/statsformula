# statsformula

**R model formulas for Python: the same terms, columns, names and numbers as R.**

statsformula is a translation of R's model-formula machinery into Python: `terms`,
`model.frame`, `model.matrix`, `update`, the *Formula* package (multi-part formulas),
`Matrix::sparse.model.matrix`, the *mgcv* smooth constructors and penalized Gaussian GAM fit,
and lavaan's model syntax. The goal is numerical and structural identity with R, not
resemblance. The same formula on the same data gives the same columns, column names,
`assign`/`contrasts` attributes and values, and the fitted models reproduce R's estimates and
their printed summaries.

On top of the design-matrix layer the package provides:

* **scikit-learn integration.** `FormulaTransformer` and `FormulaEstimator` work in `Pipeline`,
  `cross_val_score` and `GridSearchCV`, and the formula is itself a tunable hyper-parameter.
  `GAMRegressor` wraps mgcv-equivalent penalized regression.
* **Statistical models.** Gaussian GAMs with REML/GCV smoothing-parameter selection;
  systems of regression equations (path models) estimated equation by equation or by
  full-information maximum likelihood, including feedback loops and correlated
  disturbances; SEM through semopy and pySEM on lavaan's own parameter table.
* **Inference and summaries.** `summary.lm`, `summary.gam` (with Wood's smooth-term tests and
  Davies' algorithm) and lavaan's `summary()`/`fitMeasures()`, printed with R's formatting
  rules.

Every component is validated against R 4.5.1 (stats, splines, Formula, Matrix, mgcv 1.9-3,
lavaan 0.7.3) on reference fixtures generated by scripts in the repository; see
[Validation](validation.md).

```python
import pandas as pd
from sklearn.datasets import load_iris
from sklearn.linear_model import LinearRegression
import statsformula as sf
from statsformula.sklearn import FormulaEstimator

raw = load_iris(as_frame=True)
iris = raw.frame.drop(columns="target")
iris.columns = ["Sepal.Length", "Sepal.Width", "Petal.Length", "Petal.Width"]
iris["Species"] = pd.Categorical.from_codes(raw.target, ["setosa", "versicolor", "virginica"])

X = sf.model_matrix("Sepal.Length ~ Species * Petal.Length", iris)     # = model.matrix() in R
fit = FormulaEstimator("Sepal.Length ~ Species * Petal.Length",
                       LinearRegression(fit_intercept=False)).fit(iris)
print(fit.summary())                                                   # = summary(lm()) in R
```
